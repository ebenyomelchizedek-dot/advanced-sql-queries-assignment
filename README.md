# Advanced SQL Queries and Aggregations

## Project Overview
This assignment demonstrates the use of SQL aggregate functions and grouping techniques using MySQL.

## Learning Objectives
- Use aggregate functions such as `SUM()`, `AVG()`, and `MAX()`.
- Apply `GROUP BY` to organize query results.
- Use `ORDER BY` to sort records.
- Apply `LIMIT` to restrict query results.

## Database
- Database name: `sales`
- Database system: MySQL

## Assignment Questions

### Question 1: Total Payments per Date
Calculates the total payment amount for each payment date, sorts dates in descending order, and displays the five latest dates.

### Question 2: Average Credit Limit per Customer
Calculates the average credit limit for each customer and displays the customer name and country.

### Question 3: Total Price of Products Ordered
Calculates the total price of products ordered by grouping product codes and quantities ordered.

### Question 4: Highest Payment per Check Number
Finds the highest payment amount for each check number.

## File Structure
- `advanced_sql_queries.sql` – Contains all four SQL queries.
